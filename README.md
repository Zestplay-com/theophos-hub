# Theophos Hub

Create. Discover. Support. Grow.

The frontend is being rebuilt as a mobile-first HTML5/CSS3/JavaScript application and published through GitHub Pages. Firebase remains the backend for authentication, creator profiles, content, feedback and protected server operations.

## Product principle

Theophos Hub is for genuine creator discovery and support. It does not automate likes, comments or subscriptions, promise subscribers/watch hours, or operate as a sub-for-sub exchange.

## Deployment

GitHub Actions publishes the static frontend from `main` using the workflow in `.github/workflows/pages.yml`.
