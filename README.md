# Theophos Hub

Create. Discover. Support. Grow.

Creator-first growth community for small and emerging content creators.

## Status

Milestone 1 implementation is being built: landing page, authentication architecture, creator onboarding, creator profiles, dashboard, and database foundation.

## Product principles

- Genuine creator discovery, not sub-for-sub.
- No automated likes, subscriptions, comments, or fake engagement.
- Theophos metrics are kept separate from YouTube metrics.
- XP, reputation, credits, missions, and streaks are validated server-side.
- Mobile-first and PWA-ready.
